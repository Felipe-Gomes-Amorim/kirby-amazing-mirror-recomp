# Kirby & The Amazing Mirror (GBA) - recomp estatica

Projeto de estudo: recompilacao estatica do jogo de GBA (ARM7TDMI -> C/C++ nativo no PC).

- Nenhuma ROM e versionada. Coloque sua ROM legal em `baserom.gba` (ignorada pelo git).
- O recompilador le a ROM do usuario e gera o codigo; nada do jogo e distribuido aqui.
- Notas de andamento: veja `NOTES.md`.
